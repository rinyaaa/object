## 1.Value<T>クラスをイミュータブル（不変）に設計したことによる主な利点は何か

    スレッドセーフティの向上: 値が変化しないため、複数のスレッドからの同時アクセスでも問題が起きず、並行処理が簡単になります。

    予測しやすく、デバッグが容易: オブジェクトの値が途中で変わらないため、コードの動作が分かりやすく、問題発生時の原因特定が簡単です。

    ハッシュマップなどのキーに安全に利用可能: equals()やhashCode()が適切に実装されていれば、ハッシュマップのキーとして安全に使えます。

    カプセル化の強化と意図の明確化: 内部状態が外部から変更されないため、オブジェクトの設計意図が明確になり、誤用を防げます。

    共有の容易さ: コピーを作らずに安全に共有できるため、メモリ効率が良く、柔軟に扱えます。

## 2.Value<T>クラスでジェネリクス <T> を使用する主な利点は何か

    型安全性の向上: コンパイル時に型の整合性がチェックされ、実行時のエラー（例: ClassCastException）が大幅に減ります。

    コードの再利用性: どんな型の値でも格納できるため、特定の型に依存しない汎用的なオブジェクトを作成でき、コードの重複を避けられます。

    可読性と表現力の向上: クラスがどのような型の値を扱うのかが明確になり、コードの意図が伝わりやすくなります。

    キャスト不要: get()メソッドが具体的な型を返すため、値を毎回キャストする必要がなく、コードが簡潔になります。

## 3 作成した Value<T> クラスと ValueUtils のメソッドを使用例

```
// oop1.challenge07 パッケージ
package oop1.challenge07;

public class ValueExample { // クラス名は適宜設定してください
public static void main(String[] args) {
// 文字列の Value オブジェクトを生成し、動作を確認
Value<String> stringValue1 = ValueUtils.of("Hello!");
Value<String> stringValue2 = ValueUtils.of("Hello!");
Value<String> stringValue3 = ValueUtils.of("World!");

        System.out.println("--- 文字列のValueオブジェクト ---");
        System.out.println("stringValue1: " + stringValue1); // Value[value: Hello!]
        System.out.println("値を取得: " + stringValue1.get()); // Hello!
        System.out.println("nullか？: " + stringValue1.isNull()); // false

        System.out.println("stringValue1とstringValue2は等しいか？: " + stringValue1.equals(stringValue2)); // true (値が同じ)
        System.out.println("stringValue1とstringValue3は等しいか？: " + stringValue1.equals(stringValue3)); // false (値が異なる)
        System.out.println("ハッシュコードは同じか？: " + (stringValue1.hashCode() == stringValue2.hashCode())); // true

        // 整数のValueオブジェクトを生成し、動作を確認
        Value<Integer> intValue1 = ValueUtils.of(123);
        Value<Integer> intValue2 = ValueUtils.of(null); // nullを保持するValue

        System.out.println("\n--- 整数のValueオブジェクト ---");
        System.out.println("intValue1: " + intValue1); // Value[value: 123]
        System.out.println("nullか？: " + intValue1.isNull()); // false

        System.out.println("intValue2: " + intValue2); // Value[value: null]
        System.out.println("nullか？: " + intValue2.isNull()); // true
    }
}
```
